# Reflections

1. Share one aspect of building this project you found challenging and how you
   overcame it.

One of the main issues I had was importing a function from a file. I mistyped the files name when creating it so when I was importing the file I kept having issues with the program not being able to find the file and running the test. I checked everything multiple times and when I couldn't get it, I copied and pasted the error into claude and it gave me a list of commands to run in the terminal. Once I ran them and gave the results to claude, it was able to figure out that I had a typo in the file name and told me how to fix it. Once I did that I was able to get my program to work.

2. Share one technical concept that you gained a deeper understanding of
   through building this project. Explain that concept in simple terms and
   explain how it is used in your project.

A technical concept I gained a deeper understanding of through building this project is indentation and formating the orders. There were times when some lines of code were not indented. Some times the lines of code that didn't need to be indented were indented, this caused a lot of problems for me and I kept getting frusterated at myself for it. The order of the functions also matters a lot because when I was putting specific options in the menu, I had to make sure I put how python handles it in the same order so the program would not crash. Not having it in the same order would also make the program's test fail because when a user enters 1 to add a workout the system could've taken it as remove workout or complete workout. Learning to pay close attention to the order and indentation was one of my biggest take aways because something so small and simple plays a very big role in the program.
